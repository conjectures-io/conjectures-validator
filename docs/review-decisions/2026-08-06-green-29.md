## What the informal problem asks

[Green's Open Problem 29](https://people.maths.ox.ac.uk/greenbj/papers/open-problems.pdf#problem.29):

> Suppose that `A` is a `K`-approximate group (not necessarily abelian). Is there `S ⊂ A`,
> `|S| ≫ K^{-O(1)} |A|`, with `S⁸ ⊂ A⁴`?

The same conclusion **without** the `S ⊆ A` requirement is a known theorem, recorded in the pinned
source as `green_29.variant` with category `research solved` and cited to [Br13 Problem 6.5],
[CrSi10], and [Sa10]. The `S ⊆ A` requirement is the open part.

## What the published Lean task asks

At the pinned source revision, `FormalConjectures/GreensOpenProblems/29.lean` states:

```lean
theorem green_29 :
    answer(sorry) ↔
      ∃ C c : ℝ, 0 < C ∧ 0 < c ∧
        ∀ {G : Type*} [Group G] [DecidableEq G] (K : ℝ) (A : Finset G),

            ∃ S ⊆ A, C * K ^ (-c) * (A.card : ℝ) ≤ (S.card : ℝ) ∧

```

`IsApproximateSubgroup` is Mathlib's, not a local definition: a `Prop` structure with fields

The `counterexample` task asks for a kernel-checked proof of the negation.

## What the submitted proof does

Let `H` be a finite group. The construction, in `Multiplicative ℤ × H`, is

```
A  =  ({-1} × H)  ∪  ({+1} × H)  ∪  {(0, 1)}
```

— two full layers at integer coordinate `±1`, and **only the identity** at coordinate `0`. Its
cardinality is `2|H| + 1`.

**`A` is a genuine 3-approximate group.** `1 ∈ A`; `A` is symmetric because `(k, h)⁻¹ = (-k, h⁻¹)`;
and `A² ⊆ X · A` for `X = {(-1,1), (0,1), (1,1)}` with `|X| = 3`. The covering argument writes a
product of coordinate `q ∈ [-2, 2]` as `(q+1, 1)·(-1, a₂b₂)` when `q ≤ 0` and as
`(q-1, 1)·(1, a₂b₂)` when `q > 0`; in both cases the `X` factor has trivial `H`-component, so the
product's `H`-component is carried by the `A` factor. This is not a degenerate object: the true
doubling is `|A²|/|A| = 5|H|/(2|H|+1) → 5/2`.

**Why no large `S` survives.** Every element of `A` has coordinate in `[-1, 1]`, so every element of
`A⁴` has coordinate in `[-4, 4]`. If `S ⊆ A` and `S⁸ ⊆ A⁴`, then for each `s ∈ S` the eighth power
`s⁸` lies in `S⁸ ⊆ A⁴`, and `coord(s⁸) = 8 · coord(s) ∈ [-4, 4]` forces `coord(s) = 0`. The only
element of `A` at coordinate `0` is the identity. Hence `|S| ≤ 1`, while `|A|` grows without bound.

**Closing the argument.** Given any `C, c > 0`, set `α = C · 3^(-c) > 0`, choose `n > 1/α`, and take
`H = ULift (Multiplicative (Fin (n+1)))`, so `|H| = n + 1` and `|A| ≥ |H| = n + 1`. The hypothesis
would supply `S ⊆ A` with `α · |A| ≤ |S|`, giving `|S| > 1`, contradicting `|S| ≤ 1`.

## Verification of the argument

The reviewer traced each step against the pinned Mathlib and found no gap:

- `slab_pow_coord_bound` base case `m = 0` is sound: `A⁰ = {1}` and `slabCoord 1 = 0`, so the bound

## Why this is not a formalization defect

The three preceding approvals of a `FORMALIZATION_DEFECT_AWARD` — Erdős 15, Green 42, Erdős 939 —
each turned on a defective definition in the published source. That pattern does not apply here, and
the reviewer specifically tested for it:

- **The source declares no local definition.** The statement is built from Mathlib's
  `IsApproximateSubgroup`, whose three fields the construction satisfies honestly. There is no
  omitted continuity, positivity, or domain condition to exploit.
- **The exponents are load-bearing and correctly transcribed.** Were the conclusion `S⁸ ⊆ A^{O(1)}`
  rather than `A⁴`, the question would be trivial — `S = A` gives `A⁸ ⊆ A⁸`. The specific pair
  `(8, 4)` is what makes the question non-trivial, and the formalization uses it literally.
- **The counterexample is not a degeneracy.** The cheap routes to refutation are all closed:
  `A = {1}` admits `S = {1}`; large `K` drives `C · K^(-c)` toward zero and makes the requirement
  easier, not harder; `K = 1` forces `A` to be a subgroup (Mathlib's `isApproximateSubgroup_one`),
  where `S = A` works; intervals `Iₙ` and slabs `Iₙ × H` admit `S ≈ A/2`; and boxes `Iₙ^d` give a
  ratio `2^(-d)` that `C · K^(-c) = C · 2^(-dc)` still beats for `c < 1`. What makes the submitted
  example work is the hole at coordinate `0`: `A` is thick only where the eighth power escapes `A⁴`.
- **It respects the known theorem.** `S = {0} × H` satisfies `S⁸ ⊆ A⁴` with `|S| ≥ |A|/3`; it simply
  is not contained in `A`. The example is therefore a clean demonstration of precisely why the
  `S ⊆ A` requirement — the open part, as the source's own `variant` records — is the difficulty.

## Reservation: prior publication

The construction is simple — two full layers plus the identity — and simple enough that a reviewer
should ask whether it is already known in the approximate-groups literature. Two readings are open:

1. it is a genuine new observation against a question on a problem list that has not attracted
   attention; or
2. it reproduces an obstruction already recorded in the literature, in which case the target was not
   open when it was offered, as with `Erdos10.erdos_10.variants.grechuk`.

**Both readings yield `REVIEW_APPROVED` under policy `v1`,** so the payout is not blocked on
resolving this. `NOT_NOVEL` is expressly narrowed to results already present in the exact pinned Lean
environment, and this is not one. `MISATTRIBUTED_WORK` requires reliable evidence of distinctive
overlap with an identified earlier source, and none has been produced; the policy directs that an
open-ended search to create doubt after a valid result arrives is not conducted, and that unresolved
uncertainty favours approval.

submission refutes Green's Open Problem 29. Under (2) it should state that the submission formalizes
