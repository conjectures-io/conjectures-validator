# Front-end API wishlist — release notes

Additive only: no field the front reads today changes name or meaning, and nothing is removed.
Every status field below that was a plain `string` is now an `enum` in the OpenAPI document, with
the same values it always had. `docs/openapi.json` is the full contract for this release (see
"Contract file" below).

## Public fields added

| Endpoint | Field | Notes |
| --- | --- | --- |
| `GET /v1/catalog/conjectures` | `submissions_open` (top level) | Same value as `/v1/system/status` |
| `GET /v1/catalog/conjectures`, `/{slug}` | `display_status` | `open`, `in_review`, `solved`, `formalization_defect`, `solved_elsewhere`, `withdrawn`, `on_hold`, `unfunded`, `submissions_paused`. Rules in `docs/PUBLIC_API.md` → "Status, dates and links" |
| `GET /v1/catalog/conjectures`, `/{slug}` | `added_at` | When the API first listed the target; survives repins |
| `GET /v1/catalog/conjectures`, `/{slug}` | `solved_at` | When review **approved** the holder; null unless solved / formalization_defect |
| `GET /v1/catalog/conjectures/{slug}` | `source_url`, `source_patched` | Upstream file at the pin's `base_commit`; `repository_commit` does not exist upstream |
| `GET /v1/catalog/conjectures/{slug}` | `tasks[].bundle_url` | Bundle directory at the pinned tasks commit; null on retired targets |
| `GET /v1/catalog/meta`, `/{slug}` | `pins[].base_commit`, `pins[].patch_sha256`, and a `tasks` entry in `pins` | |
| `GET /v1/results/*` | `payout` | `{amount_rao, amount_usd_at_payout, paid_at, extrinsic_url, transfers[]}`; null unless REWARDED with a finalized transfer |
| `GET /v1/results/*`, `/{id}/solution`, `/in-review` | `credited_name` | `public_credit.name`, else `solver_display_name`, else null |
| `GET /v1/admin/reviews/{id}` | `decision` | The binding decision with `review_decision_id`, `kind`, `supersedes_id`; null while UNREVIEWED |
| `GET /v1/competitions/{board}/champions` | `speedup_vs_shipped` | Higher is faster; null when the chain of references is broken |

## Limits changed

| Endpoint | Before | Now |
| --- | --- | --- |
| `GET /v1/catalog/conjectures` `limit` | ≤ 100 | ≤ 500 |
| `GET /v1/competitions/{slug}/pareto` `limit` | ≤ 100 | ≤ 1000 |

## Fixed

- `GET /v1/me/rewards` `explorer_url` was built from the stored `block-extrinsic-event` reference,
  which taostats does not resolve. It is now `https://taostats.io/extrinsic/<block>-<index:04d>`,
  or null for a reference with no chain position.
- `bounty.reason` documented five values; the code produces seven. The two missing,
  `TREASURY_RESERVED` and `CHAT_LOG_REVIEW_UNAVAILABLE`, are now in the description and the enum.

## Notes for the front

- FloatLib `ratio` is the submission's total time over its champion's, so **lower is faster**.
  `speedup_vs_shipped` is the inverse direction (higher is faster). Read it rather than
  multiplying ratios: chaining in promotion order is wrong after a demotion.
- `amount_usd_at_payout` is null for every payout made before this release; only payouts the
  watcher records live from now on carry a price.
- `bundle_url` and `source_url` are null wherever the server cannot vouch for them. Render no link
  rather than building one.

## Operator steps

1. Migration `V052__treasury_payout_price.sql` (Flyway, additive: three nullable columns and three
   checks on `treasury_payouts`).
2. Optional: give the payout watcher `TAOSTATS_API_KEY` (compose already passes it through) so new
   payouts carry `amount_usd_at_payout`.
3. Production proxy: `TRUSTED_PROXY_PEERS` alone does not change the rate-limit key. Set
   `TRUSTED_PROXY_HOPS=1` as well, or every visitor keeps sharing one bucket.

## Contract file

`docs/openapi.json` is generated by `python3 scripts/export_openapi.py` and checked by
`tests/test_openapi_snapshot.py`, so it changes in the same pull request as any public response
shape. It is the production contract, which production itself does not serve.
